**Operator version:** 3.1.0

`deploy/cr.yaml` at tag v3.1.0 pins:
- `percona/percona-distribution-postgresql:18.6.1-1`
- `percona/percona-pgbouncer:1.25.2-6`
- `percona/percona-pgbackrest:2.59.0-1`

The 3.1.0 release notes say component images were rebuilt for CVEs (18.6.1-**3**, 1.25.2-**8**, 2.59.1-**2**). Users following the quickstart (`kubectl apply -f .../v3.1.0/deploy/cr.yaml`) therefore deploy the older builds. Updating the running cluster to the recommended tags worked fine (rolling update in 112 s, 3.4 s write gap), but the quickstart should deploy them from the start.

**Suggestion:** update `deploy/cr.yaml` (and the Helm chart defaults, if affected) when images are rebuilt, or note the newer tags in the quickstart.
